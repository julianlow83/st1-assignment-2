**FR-01:** The system will allow receptionists to register a new patient by entering their full name, contact number, DOB, and address.

**FR-02:** The system will allow receptionists to search existing patient records using details such as the patient's name or contact number.

**FR-03**: The system will allow receptionists to create and store doctor profiles, including their name, speciality, and assigned consultation room.

**FR-04:** The system will display a real-time list of all scheduled appointments.

**FR-05:** The system will create new appointments by linking a registered patient, an available doctor, a date and time slot.

**FR-06:** The system will automatically validate appointment slots to prevent double-booking the same doctor.

**FR-07:** The system will update an appointment's status to Scheduled, Arrived, In Progress, Completed, or Cancelled.

**FR-08:** The system will record a cancellation reason whenever an appointment status is changed to Cancelled.
