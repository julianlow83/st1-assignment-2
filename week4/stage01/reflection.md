Before using CoPilot I built a standard Python text-based app with a loop-based menu of three options, 1) Book an Appointment 2) View all Appointments and 3) Exit (i.e end the loop). The first two options were built as functions and embedded in the menu's code. I based this on last semester's Information to Information Technology (IIT) which had a similar structure. Appointments are saved as dictionaries within a list. 

Copilot helped me remember the concepts mentioned above (how to do a menu from a loop, functions, lists/dictionaries, enumerate etc.) that I had forgotten after last semester.  

CoPilot made one assumption, based on the prompt that the script should be 'beginner-friendly', it did not do any exception/error handling. So similar to mine.

CopPilot's output was verified by me pasting it's code into PyCharm and running it.
